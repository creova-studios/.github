# CREOVA Studios

**Digital Product Studio, Venture Engineering & Interactive Media**  
Ontario, Canada · [creova.one](https://www.creova.one) · Led by [Justin Mafie (`@creova-gif`)](https://github.com/creova-gif)

CREOVA Studios designs and builds digital products, interactive multilingual media platforms, and internal governance systems with strict security, accessibility, and automated verification standards.

### Public Repositories
- **[SEEN (`creova-studios/seen`)](https://github.com/creova-studios/seen)** — Multilingual (`EN`/`FR`/`ES`) interactive digital storytelling platform across React web and Expo React Native, backed by typed `demo` and Supabase Row-Level Security (RLS) data adapters.
- **[SEEN Web Artifact (`creova-studios/seen-site`)](https://github.com/creova-studios/seen-site)** — Static deployment target for `seen.creova.one` with strict Content-Security-Policy enforcement.
- **[MSK Niagara (`creova-studios/msk-niagara`)](https://github.com/creova-studios/msk-niagara)** — Bilingual academic research partnership web platform.
